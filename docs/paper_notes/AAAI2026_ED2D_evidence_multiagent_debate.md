## 1. 问题

多智能体辩论（MAD）此前被用来提高虚假信息**检测**准确率。作者认为用户不是被动接收标签的人：只标「假」不足以降低相信和转发。辩论过程里的发言、反驳和证据，本身可以当成可解释、可说服的干预文本。

ED2D 因此有两个输出：真/假标签，以及一份带证据的辩论摘要。说服实验看三件事（7 点 Likert）：对说法的相信程度、转发意愿、情感认同。

## 2. 系统结构

图 1。一场辩论五个阶段：Opening、Rebuttal、Free Debate、Closing、Judgment。

- **Agent 层**：正方、反方各 4 个智能体。画像按输入说法的领域生成，立场锁死为 True 或 Fake。同队内部把论点说圆。
- **Judge**：看完全程，打五个维度：Factuality、Source Reliability、Reasoning Quality、Clarity、Ethical Considerations。配对分数加起来等于 7，从机制上排除平局。汇总后给出 REAL 或 FAKE。
- **Orchestrator**：排角色、排轮次，并按阶段压缩共享记忆，避免上下文被早期发言撑满。
- 和 D2D 的差别：D2D 强调多维打分；ED2D 把最终输出收成「标签 + 简洁辩论摘要」，方便放进面向用户的辟谣界面。

证据模块接在 Free Debate（图注还写了 Judgment）。四步：

1. 用上下文提示从说法里抽出至多 5 个实体或概念。
2. 用这些元素查询 Wikipedia API，取回排序后的段落。
3. 再用 LLM 把每段标成 support / refute / neutral。
4. 辩手在自由辩论里引用 support 或 refute；neutral 留给法官做客观判断。

实现（第 4 节）：底座 GPT-4o。回复上限 1024 token。领域推断和终审温度 0.0；画像生成和各阶段发言温度 0.7。Free Debate 默认 1 轮，轮数可配。提示词在附录 A（会议版正文未附全文）。

图 2 的例子是「开盖冲马桶会把病原体散到空气里」。正方引用维基上的生物气溶胶摘要，反方争论文献的因果不足、会转移对主要传播途径的注意。法官因证据综合和预防原则判正方胜。图 3 是他们搭的公开社区站，用户可对自定义说法生成并查看辩论。正文没有给出站点 URL。

## 3. 检测实验（RQ1）

数据：

| 数据集 | Fake | Real | Total | 备注 |
| --- | ---: | ---: | ---: | --- |
| Weibo21 | 2373 | 2461 | 4843 | 表中合计与两项之和差 9，按原文照录 |
| FakeNewsDataset | 466 | 466 | 932 | Pérez-Rosas 等 2018 |
| Snopes25 | 252 | 196 | 448 | 2025-01 至 2025-06 的 Snopes 专业核查，每条有编辑写的解释 |

Snopes25 选在 GPT-4o 训练截止日期之后，用来降低背诵泄漏，并作为说服实验的说法来源。

基线：微调 BERT、RoBERTa；Zero-Shot、CoT、Self-Reflect、四轮双智能体 SMAD、五阶段但无外部证据的 D2D。每个 LLM 基线另有一版把同一套检索证据拼进上下文（表中 “w/ evidence”）。

Table 1 主要数字（%）：

| 方法 | Weibo21 Acc / F1 | FakeNews Acc / F1 | Snopes25 Acc / F1 |
| --- | --- | --- | --- |
| BERT | 75.64 / 77.77 | 78.30 / 79.94 | 73.55 / 74.71 |
| RoBERTa | 79.82 / 81.08 | 81.17 / 82.19 | 75.26 / 77.09 |
| D2D | 82.17 / 81.97 | 81.65 / 81.94 | 74.11 / 76.89 |
| ED2D | **83.59 / 83.18** | **84.45 / 83.41** | **77.90 / 80.40** |

证据对所有提示方法都有提升，零样本提升最大（Weibo21 Acc 67.11 → 74.26）。从 D2D 到 ED2D，各指标大约提高 2 到 3 个点；Weibo21 准确率提高 1.42 个点。作者把增益归到「结构化辩论 + 自由辩论阶段的显式检索」，而不只是把证据贴在提示词前面。Snopes25 上仍是最好，说明对训练截止后的说法有一定泛化。

Weibo21 上 ED2D 的其余指标：Prec 82.64，Rec 83.74。

Snopes25 分类计数（只统计文中给出的）：假说法 203 对 / 49 错；真说法 146 对 / 50 错。假说法准确率 \(203/252\approx 80.6\%\)，真说法 \(146/196\approx 74.5\%\)，整体 \((203+146)/448\approx 77.9\%\)，与表中 Acc 77.90 一致。

## 4. 说服实验（RQ2、RQ3）

200 名英语母语者，分成两个 100 人队列。队列内 4 个条件各 25 人。每人看 10 条真、10 条假。事先告知部分解释可能由 AI 生成且不可靠，并按判断正确给奖金。

条件：

- Control：只看说法。
- ED2D：说法 + 判断 + 解释（完整辩论记录和检索证据）。
- Snopes：说法 + 编辑写的核查。
- Combined：两份解释都给。RQ2 两份标签都正确，看叠加；RQ3 两份标签冲突，看错误 AI 能否抵消正确的人工解释。

RQ2 用 ED2D 判对的样本，RQ3 用判错的样本。分析是参与者和说法双随机截距的混合效应模型；准确率用逻辑混合模型，Likert 用线性混合模型。Tukey 校正后，条件和客观准确率、主观信念之间的差异均 \(p<0.05\)。

Table 3 摘录（Accuracy%，Belief / Share / Emotion 为 7 点均值）：

假说法、ED2D 判对（相信和转发越低越好）：

| 条件 | Acc | Belief | Share | Emotion |
| --- | ---: | ---: | ---: | ---: |
| Control | 63.60 | 3.46 | 3.15 | 3.66 |
| ED2D | 80.40 | 2.85 | 2.84 | 3.45 |
| Snopes | 85.60 | 2.77 | 2.55 | 3.15 |
| Combined | 88.00 | 2.40 | 2.53 | 3.20 |

真说法、ED2D 判对（相信和转发越高越好）：ED2D Acc 81.20、Belief 4.70、Share 4.32；Snopes 88.80 / 5.05 / 4.55；Combined 92.40 / 5.13 / 4.59。Control 为 67.40 / 3.56 / 3.06。

假说法、ED2D 判错（标签把假说成真）：

| 条件 | Acc | Belief | Share | Emotion |
| --- | ---: | ---: | ---: | ---: |
| Control | 59.60 | 3.80 | 3.09 | 3.47 |
| ED2D | 42.00 | 4.44 | 3.55 | 3.90 |
| Snopes | 81.20 | 2.97 | 2.86 | 3.55 |
| Combined | 68.00 | 3.35 | 2.95 | 3.73 |

真说法被判成假时，ED2D 把 Acc 从 Control 的 68.80 拉到 52.00，Belief 从 4.28 降到 2.95；和 Snopes 同时呈现时 Acc 只有 75.60，低于单独看 Snopes 的 82.80。

结论可以直接用于产品约束：

- 判对时，ED2D 的辟谣接近专业编辑，并能降低假说法的转发意愿。
- 判错时，同一套说服文本会提高对假说法的相信和转发；即使用户同时看到正确的 Snopes 文本，伤害只是被部分抵消，没有消失。
- 图 4：判对时各主题（科学环境、政治、医学文化、社会娱乐）和「当前事件 / 非当前」都有提升。判错时政治和娱乐掉得最多，当前事件比静态知识更脆。

Table 4 事后测验：RQ2 的 Control / ED2D / Snopes 三组，再看 10 条**没有解释**的新说法。总体准确率 66.9 / 75.9 / 78.6。ED2D 组在假说法上从对照的 73.2 提到 81.6。说明看过证据型辩论之后，用户在没有解释时也会好一些，但仍低于看过编辑核查的组。

## 5. 论文自己标出的边界

- 辩论贵。未来工作写的是更省的扩展、二元标签之外的推理，以及防止欺骗性使用。
- 证据源是 Wikipedia。中文微博谣言、突发本地事件、截图式说法，维基经常没有对应页。
- 8 个辩手 + 法官面板 + 检索分类，全部走 GPT-4o。Weibo21 四千多条若原样复现，成本和时延都不适合接进现有阻断脚本。
- 说服实验是英语 Snopes 读者，不是微博用户。转发意愿是自评 Likert，不是 weibo22 树上的真实转发。
- 检测增益相对 D2D 只有大约 1–3 个点。大头是五阶段辩论本身（D2D 已经到 Weibo21 Acc 82.17），证据是增量。

## 6. 和本仓库的关系

本仓库主线是 weibo22 上的时序阻断（`scripts/blocking_baseline.py`、`scripts/tgn_blocking.py`），内容侧的 DAMMFND 文本训练还停在 `src/text_training_round_metrics.md`：23 轮里 AUC 大致在 0.53–0.56，不能当作可靠门控。weibo22 与本地 DAMMFND 多模态表没有实例对齐（见阻断报告第 2 节）。weibo22 单帖 JSON 含 `text` 和 `original_text`，根帖文本可以直接抽，不依赖 DAMMFND 的 pkl。

ED2D 对本项目有用的是干预对象，不是另一套分类器：

- 路径阻断减少「还有多少人会转到」；内容干预减少「看到的人还信不信、还转不转」。两条指标不要合成一个 accuracy。
- 被阻断策略选中的账号，是投放辟谣的候选对象。论文的 Share 指标对应「劝这个节点不要继续转发」。
- 判错的解释会净伤害，而且能抵消正确解释。因此内容模块必须先有一个可靠的真假判断，再生成辩论。以当前文本模型的 AUC，直接对 weibo22 谣言根帖生成 ED2D 解释，期望上会制造 RQ3 那种反向说服。
- Weibo21 是两边都出现的数据集。ED2D 在上面 Acc 83.59。若要比较检测，应在 Weibo21 官方划分上比，不要把 weibo22 的树标签当成同一张表。
- 最小可运行切片是：1 个正方、1 个反方、1 个法官、1 轮、至多 5 个实体、检索段落做立场分类。8 智能体全量辩论留到这切片在小样本上证明「解释确实引用了与根帖冲突的证据」之后。
