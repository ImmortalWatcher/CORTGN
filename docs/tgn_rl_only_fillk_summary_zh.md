# 手算特征 + 强化学习：窗口结束补满名额（乙）

日期 2026-11-21。数据为 `weibo22`，沿用甲线的种子 `3074`、级联级 70/15/15 划分、1 小时观察窗口和每棵树最多 5 个阻断名额。本次从随机权重开始，在 Mac CPU 上完成。

## 一句话

测试集 311 棵谣言树的平均阻断率是 **11.88%**，比观察出度 **11.19%** 高 **0.69 个百分点**，比事后 oracle **16.01%** 低 **4.12 个百分点**。离预设的 **12.2%** 还差 **0.32 个百分点**。本次只评了 1 小时。

## 和对照差在哪里

甲乙共用 REINFORCE 训练和选点流程。乙用粉丝数、距根时间、深度、当前出度、祖先是否被选、剩余名额、已选人数和新近程度给动作打分。甲还会在每条转发到来时更新并使用 GRU 记忆。两边都允许在窗口里等待，屏蔽已选节点的下游，窗口结束时补选剩余名额。

| 数据 | 平均选中人数 | 花满 5 个名额 | 一个都不拦 | 阻断率 |
| --- | ---: | ---: | ---: | ---: |
| 验证集 305 棵 | 4.62 | 86.6% | 0% | 11.18% |
| 测试集 311 棵 | 4.55 | 83.9% | 0% | 11.88% |

## 测试集对照

| 方法 | 1 小时、`k=5` |
| --- | ---: |
| 观察出度 | 11.19% |
| 甲线补名额版 | 11.50% |
| 乙线补名额版 | **11.88%** |
| 事后 oracle | 16.01% |

按整棵树划出的训练、验证和测试数分别是 3,264、698 和 702 棵。筛选后有 2,960 棵可训练，验证和测试分别对 305 和 311 棵可评谣言树打分。复跑得到测试出度 **11.1907%**、oracle **16.0071%**，和甲线对得上。训练日志也记录了打乱窗口外结构后的泄漏自检。

## 训练是怎么停的

验证用最高分动作，关闭奖励塑形。最多训 20 轮，验证阻断率连续 3 轮没有提高就停。

第 10 轮触发早停，测试重新加载第 7 轮权重。训练约 **319.1 秒**，验证约 **28.9 秒**，合计 **5 分 48 秒**。读数据和最终测试另计。

## 这一版说明了什么

乙线在同一批测试树上比历史甲线补名额版高 **0.38 个百分点**，两边平均选中的节点数接近。这是各自一轮训练的对照。把结论扩展到不同种子或设备，需要对应的重复实验。

## 复现入口

从仓库根目录运行，`--tag` 使用新的名字。

```bash
python -u scripts/tgn_rl_blocking.py --policy features --device cpu \
  --window time:1h --k 5 --seed 3074 --force-fill \
  --epochs 20 --patience 3 --tag rl_only_fillk_repro
python scripts/tgn_rl_blocking.py --policy features --device cpu \
  --window time:1h --k 5 --seed 3074 --force-fill \
  --count-selected --tag rl_only_fillk_repro
```
